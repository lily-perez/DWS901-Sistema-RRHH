# DWS901 - Sistema de Gestión de Solicitudes de Recursos Humanos

Proyecto desarrollado para la asignatura DWS901.

## Descripción

El proyecto consiste en el desarrollo de un Sistema de Gestión de Solicitudes de Recursos Humanos, orientado principalmente a la administración de solicitudes de vacaciones y permisos dentro de una organización.

El sistema permitirá centralizar las solicitudes, controlar los flujos de aprobación según el rol de cada usuario, validar los días disponibles de vacaciones y mantener la trazabilidad de las decisiones realizadas durante cada etapa del proceso.

## Tecnologías y herramientas definidas

- Node.js: desarrollo del backend.
- MySQL: persistencia de la información.
- Figma: elaboración de mockups y prototipo navegable.
- Git y GitHub: control de versiones y repositorio del proyecto.

## Estructura inicial del backend

```text
src/
├── routes/
├── controllers/
├── services/
└── models/
```

### Responsabilidad de los componentes

- **Routes:** definición de las rutas de acceso a las funcionalidades.
- **Controllers:** procesamiento de las solicitudes recibidas desde la interfaz.
- **Services:** lógica y reglas de negocio del sistema.
- **Models:** representación y gestión de los datos y persistencia.
